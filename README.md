# WissMotion

Estudio local para crear **videos promocionales adaptados a la marca**, con calidad visual inspirada en Jitter.

El producto vive en [`wissmotion/`](wissmotion/README.md). Plan completo en [`wissmotion/ROADMAP.md`](wissmotion/ROADMAP.md).

## Figma

Puedes partir de un diseño de Figma: se importan assets, tokens (colores, tipografías), componentes y frames, y se convierten en movimiento dentro de la composición. Se hace con la skill `/figma` de HyperFrames. La importación de variables y logo directo al brand kit está en el [roadmap](wissmotion/ROADMAP.md).
