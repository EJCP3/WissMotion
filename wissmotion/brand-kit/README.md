# Brand Kit (Fase 1)

Todo lo propio de marca vive aquí. El contrato es `brand.schema.json` (v1);
la IA, los agentes externos y el editor manual leen y escriben los mismos
archivos.

## Archivos

| Archivo                                                  | Qué es                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `brand.schema.json`                                      | Contrato versionado (`brandVersion: 1`). Obliga: nombre, 6 colores hex, fuentes. Opcional: tagline, URL, logo (5 variantes), tono, `motionPersonality`, features, CTA, capturas, redes.                                                                                                                                                                                                                                                            |
| `brand.example.json`                                     | Ejemplo válido.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `validate-brand.mjs`                                     | `node validate-brand.mjs <brand.json>` → exit 0/1 (Ajv draft 2020-12).                                                                                                                                                                                                                                                                                                                                                                             |
| `brand-tokens.mjs`                                       | `brandToCss(brand)` → `:root { --brand-*: … }` para inyectar la marca en composiciones. También CLI: `node brand-tokens.mjs brand.json tokens.css`.                                                                                                                                                                                                                                                                                                |
| `extract-lib.mjs` + `extract-from-url.mjs`               | Extractor sin IA: `node extract-from-url.mjs <url> --out brand.json [--screenshots dir] [--timeout ms] [--save nombre] [--brands-dir dir]`. Lee HTML + CSS propio (máx. 5 hojas, mismo origen), deriva colores por frecuencia, fuentes (Google Fonts + CSS), favicon (SVG > PNG > ICO) y metadatos. `--screenshots` corre `hyperframes capture` y deja el plate desktop; móvil queda pendiente (capture no emula viewport móvil).                  |
| `extract-from-images.mjs` (`wissmotion brand-images`)    | Marca desde capturas de la app (App Store, Play Store o sueltas): `node extract-from-images.mjs a.png b.jpg --name "App" [--primary #hex] [--logo icono.png] --out b.json`. FFmpeg reduce cada imagen; fondo = color de más área, texto = el de más contraste, primario/secundario = candidatos por tono (área × saturación). Imprime los candidatos: si un gráfico le gana al color de marca, repite con `--primary`. Fuentes: Inter por defecto. |
| `enrich.mjs` (`wissmotion brand-enrich`)                 | **IA opcional**: `node enrich.mjs b.json [--url …] [--notes "…"] [--overwrite]`. Claude (`claude-opus-5-5`, o `WISSMOTION_AI_MODEL`) propone tono, tagline, beneficios, CTA y personalidad de movimiento con salida JSON estructurada; rellena solo lo que falta. Público y guion (4-6 escenas) van a `b.enrich.json`. Credenciales del SDK (`ANTHROPIC_API_KEY` o `ant auth login`); requiere `npm install` en `wissmotion/`.                     |
| `brand-library.mjs`                                      | Biblioteca: guardar, listar, duplicar, borrar, exportar e importar marcas en `~/.wissmotion/brands` (override `--brands-dir` o `WISSMOTION_BRANDS_DIR`). Todo validado antes de entrar.                                                                                                                                                                                                                                                            |
| `brand.test.mjs`, `extract.test.mjs`, `library.test.mjs` | Tests `node:test` (van en `test:scripts` del `package.json` raíz).                                                                                                                                                                                                                                                                                                                                                                                 |

## Reglas de mapeo (deterministas)

background = color más claro · text = más oscuro · surface = blanco (si no
es el fondo) si no 2.º más claro · primary/secundaria = cromáticos más
frecuentes · accent = más saturado · heading/body = Google Fonts en orden de
carga, si no CSS por frecuencia · pesos = los declarados, si no `[400, 700]`.
Sin colores → paleta neutra. Todo lo que el extractor no puede saber
(features, tono, CTA) se completa a mano o con IA (Fase 7).
